一份记忆，多设备、多 agent 共用。只有两个资产：整理后的笔记与原始转录，其余都是可替换的外壳。

资产（必须长期保存） 外壳（可替换） Syncthing 双向同步 rsync 单向归档 dreaming 读取 A 全自动 B 可撤销 C 需确认
记忆读写agent 读写本地 vault 副本，Syncthing 与服务器双向同步。会话中只追加 log/，且按设备分文件，多端同时写几乎不冲突。
转录归档各 agent 的原始转录用 rsync 单向推到服务器。本地被清理后服务器仍保留，只供 dreaming 读取。
自动整理每天处理一次增量。A、B 级直接写回 vault；C 级写入 proposals/，任意 agent 下次启动时提醒你确认。
